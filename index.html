在 GitHub 反馈问题 ↗
这是 WITRN 官方软件吗？

这是 Andyshenjx 独立开发的第三方工具，与 WITRN / 维简官方无关联，未获官方授权或背书。相关名称、商标和标识归各自权利人所有。

可以用它修改设备内部设置吗？

应用提供测量、记录、分析及已适配的 K2 维护功能，不提供设备内部设置或设备内部历史记录读取。正常测量与抓包只接收 HID 输入，不发送诱骗命令。

可以编辑表盘、更新固件吗？

K2 提供表盘背景、布局与开机图编辑，以及独立 DFU 维护功能。C5、U3 未适配这些写入功能。固件升级和个性化写入未经实机验证，使用前请阅读版本说明及项目文档。

PD 解码结果可以直接作为最终结论吗？

请结合原始报文与实际设备判断。程序保留原始十六进制，CRC 未校验；缺少上下文时不会猜测 RDO 物理量。测量与协议结果仍需结合实际设备核对。

在哪里获取帮助或提交反馈？

先查看使用指南。如果问题仍然存在，请在 GitHub Issues 提供 macOS 版本、Mac 芯片、功率表型号、固件版本与复现步骤。
