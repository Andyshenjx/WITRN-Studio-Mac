WITRN STUDIO / 3.3.0

从连接，到第一条记录。

一根数据线，一个 HID 接口，在 Mac 上开始观察与记录。

01 / 下载与连接

从 GitHub Releases 下载版本，将解压后的 App 放入「应用程序」。网站面向 macOS 14+、Apple Silicon；Intel 用户请查看源码说明。

使用具备数据传输能力的 USB 线连接功率表的电脑 HID 接口。在「设备」页重新扫描，核对 USB 名称、VID/PID 与识别结果后连接。先在兼容性页面确认你的型号范围。

02 / 观察与保存

进入「仪表」查看实时曲线。时间窗口决定显示范围，刷新率决定数字与图表更新频率，记录间隔决定 CSV 保存频率。点击「开始记录」才会创建测量 CSV；暂停与数据间隙不跨段积分。

「本次测量」是 Mac 端积分，「设备累计」是功率表上报的计数。旧款缺少设备累计时显示空值，使用本次测量即可。打开历史 CSV，可缩放曲线、选择区间查看容量和能量统计。

03 / K2 的协议与线阻

PD 抓包需在 K2 设备菜单打开 PD 联机开关。默认连接后自动保存抓包，CSV 与抓包文件独立；也可打开历史 K2PD 文件离线查看。

线阻功能要求 K2 固件 5.5–5.8，在设备上打开对应 4/8 线页并完成测量，再在 App 读取。软件记录最近设备结果，读取次数不代表独立测量次数。

04 / 个性化与设备维护

导入图片制作背景，或打开官方 .k2pic / .c4cfg、BMP、ZIP 资源包编辑布局。K2 背景 240 × 240，开机图 235 × 235；C4/C4L/C5 背景 320 × 172。预览字体为替代显示。

写入前保存资源并按对应型号说明进入 DFU。K2 按住减号键上电，C4/C4L/C5 按住 OK 上电；App 确认设备身份后才提供维护。C4 系列背景与参数分别写入，写入后需在设备表盘页长按 OK 切换。新增维护路径仍待实机确认。

05 / 没有数据时

检查数据线与 HID 接口，关闭其他占用设备的软件，允许 macOS USB 配件连接，再重新扫描。已连接不等于已收到有效测量；展开连接诊断检查输入计数与最近报告。

在「设备 → 原始 HID 试抓取」保存日志，添加设备屏幕读数及操作标记，停止后导出完整 JSONL。旧款连接保留正常测量查询，日志功能不额外发送命令。反馈时附型号、固件、macOS 版本与日志，并检查序列号等个人信息。
