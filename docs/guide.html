01 / 下载与安装

先准备好你的 Mac。

  1. 核对设备和版本先在兼容性页面确认型号范围，再查看 GitHub Releases 中对应发行版的功能说明。
  2. 下载并放入「应用程序」下载 Mac 应用包，解压后把 App 放入「应用程序」文件夹。当前下载面向 macOS 14+、Apple Silicon；Intel Mac 请参阅源码说明。
  3. 打开应用如系统阻止打开，先确认下载来源，再按 macOS 提示到「系统设置 → 隐私与安全性」中处理。

网站介绍的是 3.3.0 功能范围。历史下载包可能使用旧名称或尚未包含新增功能，以实际发行版说明为准。

02 / 连接功率表

连对接口，确认识别。

  1. 用数据线连接电脑 HID 接口使用具备数据传输能力的 USB 线，把功率表的电脑 HID 接口连接到 Mac。仅支持充电的线缆无法用于联机。
  2. 在「设备」页重新扫描核对 USB 产品名称、VID / PID、型号识别结果和测量连接方式，再选择连接。按 macOS 提示允许 USB 配件连接。
  3. 等待有效测量进入「仪表」，确认电压、电流等读数开始更新。若显示「已连接，等待有效测量」，请展开连接诊断查看输入计数与最近报告。

新增型号仍待实机验证。陌生接口的「尝试测量连接」只用于接收测量，不开放 PD 或设备维护；识别到型号也不代表该固件已验证通过。

03 / 观察与记录

看曲线，也把过程存下来。

在「仪表」中查看实时读数，使用主图和底部全程导航缩放、平移或选择时间范围。光标显示采样点的读数；右侧大数字始终显示当前实时值。

先分清三个设置

时间窗口、刷新率与记录间隔的区别
设置决定什么
时间窗口主图显示多长一段过程。
刷新率图表与实时数字每秒更新多少次，独立于设备采样。
记录间隔CSV 每隔多久保存一个实际收到的采样点；开始记录时固定。

创建一份 CSV

点击「开始记录」才会创建测量 CSV。记录过程中可以暂停、继续与结束；暂停或数据间隙不会跨段积分。断开设备会结束记录，系统休眠后需要手动继续。

打开本软件或官方四列 CSV，可以重新选择时间区间，查看容量、能量与统计占比。浏览历史记录时，设备采集和当前文件记录仍可继续。

两种容量读数的来源

本次测量

Mac 根据收到的测量数据计算 mAh / Ah / Wh，连接后即可累计，无需先创建文件记录。

设备累计

来自功率表上报的计数。旧款实时帧没有这些字段时显示为空，请使用「本次测量」。

04 / K2 协议与线阻

需要时，再深入一层。

K2 · PD 抓包

先开启 PD 联机

按 K2 说明要求使用固件 4.6 或更新版本，在设备菜单打开「PD 联机开关」，然后连接 App。程序不远程修改这个开关。

默认连接后自动保存 PD；可在设置中关闭。CSV 和 K2PD 独立保存，没有实际报文时不会创建空抓包文件。历史 K2PD 可离线打开。

K2 · 固件 5.5–5.8

先测量，再读线阻

在设备上进入对应的 4 / 8 线页面并完成测量，再在 App 的「线阻测量」页读取结果，按需记录或导出专用 CSV。

软件读取设备保留的最近结果，不会主动开始测量。同一结果反复读取，不代表多次独立测量。

PD 解码保留原始十六进制，CRC 未校验。判断协商结果时请结合上下文和设备表现；线阻记录也需与设备上的实际测量对应。

05 / 表盘与维护

先在 Mac 编辑，再写入设备。

导入图片制作背景，或打开官方 .k2pic / .c4cfg 布局、BMP 与 ZIP 资源包。调整构图、元素位置和样式后，先保存资源，再选择对应设备的写入步骤。

K2 与 C4 系列表盘资源的格式和尺寸

表盘背景240 × 240 BMP320 × 172 BMP
布局参数.k2pic · 17 项元素.c4cfg · 12 项元素
开机图235 × 235 BMP未适配

预览字体为替代显示；C4 系列在编辑器中使用 C5 作为共用资源格式选项。请保持资源与设备型号一致。

K2：写入表盘或开机图
  1. 完成编辑并保存所需的背景、布局或开机图。
  2. 完全断电，按住减号键上电，通过电脑 HID 数据口连接 Mac，进入 DFU。
  3. 等待 App 确认 K2 设备身份，核对资源后选择对应写入操作。
  4. 查看任务结果与日志，再按对应资源说明恢复正常使用。
C4 / C4L / C5：背景和布局分别写入
  1. 确认固件为 3.0 或更新版本，保存同型号的背景和 .c4cfg 参数。
  2. 完全断电，按住 OK 键上电，连接电脑 HID 数据口，屏幕显示 DFU 后松手。
  3. 由 App 确认设备身份，先写入其中一项。首次使用时，背景和参数都需要写入。
  4. 每项完成后拔线，下一项重新进入 DFU 并检测；已有完整配套资源时，可仅更新修改的一项。
  5. 正常上电进入设备表盘页，长按 OK，在内置表盘和自定义表盘之间切换。

写入背景不会自动切换当前表盘，仅写图片也不能证明自定义表盘已具备有效参数。

固件与虚拟 E-Marker

固件升级和虚拟 E-Marker 设备读写目前限 K2，使用独立的 DFU 身份检查。离线编辑虚拟配置不要求连接设备；虚拟参数不会增加实体线材的承载能力。

详细操作参阅项目中的固件维护说明与E-Marker 说明。新增维护路径仍待实机确认，实际开放范围以下载版本为准。

06 / 排查与反馈

从当前状态，找到下一步。

扫描列表里没有设备

确认使用的是电脑 HID 接口和支持数据传输的 USB 线。检查 macOS 是否允许 USB 配件连接，关闭其他可能占用功率表的软件，再重新扫描。

已经连接，但没有有效读数

展开「连接诊断」，查看输入计数、报告长度与最近原始报告。连接状态只说明接口已打开，不代表已收到有效测量。旧款查询报错后需要断开再连接。

K2 没有 PD 报文

先确认设备的 PD 联机开关已开启。App 只能记录 HID 连接之后 K2 实际上报的报文，无法补回此前发生的协商。再检查抓包是否已结束、筛选条件是否隐藏了消息。

C4 / C5 写入后仍是原来的表盘

正常上电后进入设备表盘显示页，长按 OK 切换。若仍无法切换，核对配套背景和 .c4cfg 是否都已写入。单项读回校验成功不能证明另一项资源已存在，也不能代替实际显示结果。

仍有问题时，带上这些信息

在「设备 → 原始 HID 试抓取」保存日志，添加设备屏幕读数与操作标记，停止后导出完整 JSONL。日志功能不额外发送命令，旧款正常测量查询仍按连接路径执行。

  • 功率表型号与固件版本
  • macOS 与应用版本
  • 问题发生前的具体操作
  • 诊断日志和设备屏幕读数

分享日志前，可检查并移除不需要公开的序列号等个人信息。
