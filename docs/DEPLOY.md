# 维简 Studio 网站 · 3.3.0 排版更新

纯静态四页网站，无依赖，无需构建。此次更新重排首页浏览路径，按工作流组织功能截图，加入型号选择和功能矩阵，整理分步指南及移动端导航。

## 文件与页面

- `index.html`：首页，按了解功能、确认型号、下载上手的顺序组织。
- `features.html`：测量与记录、协议与线材、表盘个性化、设备与维护四组功能，保留全部十张功能截图。
- `compatibility.html`：19 款型号选择与完整矩阵；型号选择读取矩阵数据，避免两处内容不一致。
- `guide.html`：安装、连接、记录、K2、表盘与排查六个步骤，提供页内目录。
- `styles.css` / `site.js`：共享排版、移动端导航辅助、目录高亮、截图放大与型号选择。
- `assets/`：原始截图、应用图标与赞赏码。
- `sitemap.xml` / `robots.txt` / `.nojekyll`：搜索入口及 GitHub Pages 静态发布文件。

关闭或无法加载 JavaScript 时，页面导航、完整型号矩阵、使用指南和图片原图链接仍可使用；型号选择器会隐藏，移动端菜单与问答使用浏览器原生折叠组件。

## 重新上传

推荐使用项目根目录的 **WITRN-Studio-Website-3.3.0-redesign.zip**。压缩包内的网站文件直接位于根层，没有额外套一层目录；解压后上传内容，不要上传 ZIP 本身来代替网页。

保留 GitHub Pages 现有发布来源：

1. 若为 `main → / (root)`，将压缩包解压后的四个 HTML、`styles.css`、`site.js`、`assets/`、`sitemap.xml`、`robots.txt` 和 `.nojekyll` 放入仓库根目录，覆盖同名网站文件。
2. 若为 `main → /docs`，将同一套文件更新到仓库的 `docs/` 目录。项目内 `docs/` 也已同步相同内容。
3. `assets/` 必须一起上传并保持名称和层级。仅上传 `index.html` 不会更新其他页面、样式或交互。
4. 保留仓库原有的项目 README、许可证、Google 验证文件、应用下载文件及其他非网站内容。压缩包中的 `DEPLOY.md` 只是说明，可留在仓库或不上传。

所有页面使用相对链接，适用于仓库根站点及 `WITRN-Studio-Mac/` 项目路径。共享 CSS 和 JS 已更新资源版本参数，减少旧缓存造成的样式混用。保留既有 GA4 配置、canonical、Open Graph 与软件结构化数据。

## 本地交付

`website-root/` 为网页源文件目录；`docs/` 与 `WITRN-Studio-Website-3.3.0/` 中的同名网站文件已同步。源文件目录中已有的旧截图副本保持原样，上传压缩包仅收录当前页面需要的 assets 资源。

按用户要求，未编译、未启动本地服务器、未打开浏览器、未执行网页交互或应用运行验证。只做静态文件检查：HTML 结构、页面 ID、链接与锚点、图片引用、JSON-LD、19 个唯一型号及各目录文件一致性。实际页面呈现和交互效果仍待用户打开确认。

网站的适配说明来自当前项目文档。新增型号和维护路径尚待实机验证，截图不作为设备兼容性或下载包已包含所有功能的证明。
