新版共同测量

K2、C4 / C4L / C5、U3 / U3L / U3LP、A2 / A2L / A2C 接入共同测量路径。A2 固件需 2.1 起、A2L 需 1.6 起；A2 系列仅有一组设备容量。U3L Pro 按 U3LP 识别。

旧款查询测量

U2 / U2P / X 使用旧款查询；C0 / C0s / C1 / C3、A0 / A1 为实验性适配。实时帧缺少设备 Ah / Wh、运行时间与组号，软件积分和 CSV 仍可使用。

表盘与维护要求

K2 的表盘、开机图与维护操作须确认 K2 DFU 身份，线阻读取限定固件 5.5–5.8。C4 / C4L / C5 的表盘要求固件 3.0 起，使用独立 DFU 路径；固件和虚拟 E-Marker 设备操作仍限 K2。

尚未覆盖的型号

A2Q 不具备电脑联机功能。CC1、C2、C0Q / C0+、U3SE / MFI、C5X / C5L 未计入适配型号。扫描到 USB 接口，不等于已确认具体型号或协议。
